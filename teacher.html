🔒 목적지별 비밀 메시지

학생이 해당 장소에 도착해 보물상자를 열 때만 메시지가 공개됩니다. 한자, 단어, 숫자, 문장 모두 가능 (최대 30자).

🏙 목적지 이름 (간판 · 안내 문장에 사용)

건물 모양은 고정이고 간판 글자와 안내 문장에 쓰이는 이름을 바꿀 수 있어요. 바꾼 뒤 학생 화면을 새로고침하면 간판에 반영됩니다. 양사는 「前面有一家银行」 문장에 쓰여요.

건물중국어병음한국어양사一+양사 병음아이콘

🗣 중국어 안내 문장과 음성

• {dest} = 목적지 이름, {mw} = 양사, {destPy}·{mwPy} = 병음, {destKo} = 한국어 이름 으로 자동 바뀝니다.
• MP3 등록: 녹음한 MP3 파일(300KB 이하 권장)을 올리면 학생 화면에서 브라우저 음성 대신 MP3가 재생돼요. 목적지 이름이 들어간 문장({dest})은 브라우저 음성으로만 읽어요.
• MP3가 없으면 브라우저의 중국어(zh-CN) 음성 합성으로 자동 재생됩니다.

⚙️ 게임 설정

제한 시간은 다음 게임 시작부터 적용됩니다. 진행 중에는 대시보드의 「＋5분」 버튼을 쓰세요.

🧹 초기화

새 반 수업을 시작하기 전에 누르세요. 모든 학생의 참가 기록과 수집 결과가 지워지고 게임이 「대기 중」으로 돌아갑니다. (비밀 메시지 · 문장 · 설정은 유지)

설정 · 문장 · 목적지 이름 · 비밀 메시지 · 음성 파일을 모두 처음 상태로 되돌립니다.

📘 수업 진행 순서

  1. 수업 전: 「비밀 메시지」 탭에서 메시지 10개 입력 → 저장. 「🧹 게임 결과 초기화」.
  2. 학생들에게 학생 접속 주소를 알려 줍니다 (상단 🔗 버튼으로 복사).
  3. 학생들이 이름(번호)을 입력하고 참가 → 대시보드에 이름이 나타나는지 확인.
  4. ▶ 게임 시작 → 학생 화면에 3·2·1 카운트다운 후 출발!
  5. 10개를 모두 모은 학생은 자동으로 「완주」 처리되고 순위가 매겨집니다 (서버 시각 기준).
  6. 학생이 학습지를 제출하면 확인 후 「승인」 버튼 → 학생 화면에도 승인 표시.
  7. 수업 끝: ⏹ 종료. 다음 반 수업 전에 다시 초기화.

🆘 자주 생기는 상황

  • 학생이 컴퓨터를 바꿨어요 → 학생이 「컴퓨터를 바꿨어요」 버튼을 누르면 대시보드 위에 요청이 뜹니다. 「승인」하면 기존 기록이 새 컴퓨터로 옮겨져요.
  • 소리가 안 나요 → Chrome 또는 Edge 사용, 컴퓨터 볼륨 확인, 학생 화면 ⚙️ 설정의 「음성 테스트」.
  • 이름을 잘못 입력했어요 → 표에서 🗑 로 삭제 후 다시 참가.
  • 장난치는 학생 → ⛔ 차단 (차단 해제 가능).
