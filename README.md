# 寻找隐藏的信息 선생님이 숨겨둔 메시지를 찾아라!

중학교 2학년 중국어 「你去哪儿？」 단원용 **3D 중국 도시 탐험 게임**입니다.
학생은 중국어 길 안내(글자 + 음성)를 듣고 캐릭터를 직접 움직여 10개 목적지를 찾아가고, 보물상자 속 비밀 메시지를 모아 학습지에 적습니다.

- **노트북 · 태블릿 · 휴대폰** 모두 가능 (와이파이 · 데이터 상관없음)
- 서버를 쓰지 않아 **비용 0원, 동시 접속 인원 제한 없음**
- 회원가입 · 설치 · 선생님 설정 없음: **주소(QR) 하나로 모든 선생님과 학생이 같은 게임**을 합니다

---

## 1. 수업 진행 방법

1. 학생들에게 게임 주소(또는 QR)를 알려 줍니다.
   `https://kyulaoshi.github.io/7.niqunar/`
2. 학생은 이름(번호 + 이름 추천)을 입력하고 「게임 참가」 → 3·2·1 후 출발합니다.
3. 화면 왼쪽 미션 「我去○○。」과 중국어 길 안내를 보고 들으며 목적지를 찾아갑니다.
4. 목적지 앞 빛나는 보물상자를 열면 비밀 메시지가 나옵니다 → 학습지에 기록합니다.
5. 10개를 모두 모으면 완주 화면이 나옵니다. 학습지를 먼저 제출한 학생이 우승!

**제한 시간 (기본 20분)**
- 시간은 학생마다 「게임 참가」를 누른 순간부터 잽니다.
- 시간이 끝나면 게임이 종료되고, 그때까지 모은 메시지 목록을 보여 준 뒤 **기록이 초기화**됩니다. 다음 학생(다음 반)은 같은 기기에서 처음부터 시작할 수 있어요.
- 제한 시간 안에는 새로고침하거나 브라우저를 껐다 켜도 기록이 이어집니다.

**조작 방법**
- 노트북: `WASD`/방향키 이동 · `Shift` 달리기 · `Space` 점프 · `E` 보물상자 열기 · 마우스 드래그 시점 · 휠 확대
- 태블릿 · 휴대폰: 왼쪽 아래 조이스틱 이동(끝까지 밀면 달리기) · 「점프」 · 「열기」 버튼 · 화면 밀어서 시점 · 두 손가락 확대/축소
- 휴대폰은 **가로 화면**을 추천합니다. 느린 기기는 자동으로 가벼운 그래픽이 됩니다.

## 2. 메시지 · 제한 시간 · 제목 바꾸기

모든 설정은 **`js/lesson.js` 파일 하나**에 있습니다.

```js
export const LESSON = {
  title: '寻找隐藏的信息',   // 게임 제목
  durationMin: 20,             // 제한 시간(분)
  showKorean: true,            // 「한」 버튼(한국어 뜻 보기) 허용
  secret: '1A0g...'            // 비밀 메시지 10개 (학생이 미리 볼 수 없게 섞은 값)
};
```

- 제목 · 제한 시간은 숫자와 글자만 바꾸면 됩니다.
- **비밀 메시지**는 섞어 둔 값이라 직접 고치기 어렵습니다. 바꾸고 싶으면 새 메시지 10개를 Claude에게 알려 주고 새 `lesson.js`를 받아 덮어쓰세요.
- 파일을 바꿔 올리면 1~2분 뒤 모든 학생에게 적용됩니다. (메시지나 시간을 바꾸면 학생 기기의 이전 기록은 자동으로 새로 시작됩니다)

## 3. GitHub에 올리기 · 바꾸기

**처음 올릴 때**
1. GitHub → **＋ → New repository** → 이름 입력 → **Public** → Create
2. **uploading an existing file** → 압축을 푼 폴더 **안의 내용물 전체**를 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Branch **main** / **/(root)** → **Save** → 1~3분 뒤 주소가 나옵니다

**파일을 바꿀 때 (예: lesson.js)**
1. 저장소에서 해당 폴더(`js`)로 들어갑니다.
2. **Add file → Upload files** → 새 파일 끌어다 놓기 → **Commit changes** (같은 이름이면 덮어씁니다)
3. 1~2분 뒤 반영됩니다. 안 바뀌어 보이면 `Ctrl + F5`

## 5. 게임 구성

- **도시**: 5×5 도로망(교차로 · 횡단보도), 성벽과 망루, 계림풍 산, 달리는 기차, 등롱 · 가로수 · 분수 · 보탑
- **목적지 10곳**: 学校 · 医院 · 银行 · 超市 · 公园 · 饭店 · 火车站 · 图书馆 · 商店 · 邮局 (각각 다른 3D 건물 · 중국어 간판 · 떠 있는 아이콘 · 보물상자)
- **도착 판정**: 보물상자 반경 6.5m 안에 들어와야만 열 수 있고, 메시지는 상자를 연 순간에만 화면에 나옵니다.
- **길 안내**: 도로망의 실제 최단 경로를 계산해 캐릭터가 바라보는 방향 기준으로 「请往前走 / 前面有一个路口 / 到了路口，往左拐 / 请往回走 / 你走错路了 / 前面有一家银行 / 目的地快到了 / 恭喜你，找到了」를 글자 · 병음 · 음성으로 안내합니다. 같은 안내가 짧은 시간에 반복되지 않습니다.
- **미션 순서**는 학생마다 다르게 섞여 서로 따라가기 어렵습니다.

## 6. 알아 두실 점

- **사용량**: 학생 한 명이 처음 접속할 때 약 0.25~1MB를 받습니다. GitHub Pages 권장 기준(사이트당 월 100GB)으로 한 달 약 10만 번 접속할 수 있어요. 넘어도 요금은 청구되지 않습니다.
- **비밀 메시지 보안**: 화면에는 도착 전까지 절대 보이지 않지만, 서버가 없는 방식이라 개발자 도구를 다룰 줄 아는 학생이 마음먹으면 미리 알아낼 가능성은 있습니다.
- **같은 메시지 공유**: 모든 반이 같은 메시지를 쓰므로 먼저 수업한 반이 답을 알려 줄 수 있습니다. 걱정되면 반마다 `lesson.js`를 바꿔 올리세요.
- **중국어 음성**: 기기에 들어 있는 중국어(zh-CN) 음성을 씁니다. Chrome · Edge · 아이폰 · 아이패드 · 갤럭시 대부분에서 나오며, 소리가 안 나도 글자와 병음은 항상 보입니다. 아이폰은 무음 모드에서 효과음이 안 들릴 수 있어요.
- **동시 시작 · 실시간 순위표**는 없습니다. 출발은 선생님이 말로 신호를 주고, 순위는 학습지 제출 순서로 정합니다.
