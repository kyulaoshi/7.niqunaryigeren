# 寻找老师的秘密！ 선생님의 비밀을 찾아라! (Find the Teacher’s Secret!)

중학교 2학년 중국어 「你去哪儿？」 단원용 **3D 중국 도시 탐험 게임**입니다.
학생은 중국어 길 안내(글자 + 음성)를 듣고 캐릭터를 직접 움직여 10개 목적지를 찾아가고, 보물상자 속 비밀 메시지를 모아 학습지에 적습니다.

- 학생 화면: `index.html` (노트북 · 태블릿 · 휴대폰)
- **선생님 수업 QR 만들기: `make.html`** ← 기본으로 쓰는 방법 (가입 · 설치 · 비용 없음)
- (선택) 실시간 관리자: `teacher.html` + Firebase 연결 도우미 `setup.html`

빌드 과정이 없는 순수 HTML/JS 프로젝트라서 **파일을 그대로 GitHub에 올리면 바로 작동**합니다.

## 0. 가장 쉬운 사용법: 수업 QR (추천)

서버를 쓰지 않는 방식이라 **비용 0원, 접속 인원 제한 없음, 회원가입 · Firebase 설정 필요 없음**입니다.

**선생님**
1. `https://내아이디.github.io/저장소이름/make.html` 을 엽니다.
2. 제목, 제한 시간, **비밀 메시지 10개**를 입력하고 「🎫 수업 QR 만들기」를 누릅니다.
3. 「🖥 QR 크게 띄우기」로 TV에 띄우거나, 링크를 클래스룸 · 채팅방에 올립니다.

**학생** (노트북 · 태블릿 · 휴대폰, 와이파이 · 데이터 모두 가능)
1. QR을 찍거나 링크로 들어가 이름 입력 → 3·2·1 후 출발 (시간은 각자 출발한 순간부터)
2. 보물상자 10개를 열어 비밀 메시지를 학습지에 적기
3. 다 모으면 나오는 **기록 카드**(걸린 시간 · 확인 코드)를 학습지와 함께 선생님께 보여 주기

**순위 · 확인**
- 학습지와 기록 카드를 **제출한 순서**로 순위를 정합니다.
- 기록 카드가 의심스러우면 `make.html` 아래 「기록 카드 확인」에 이름 · 시간 · 확인 코드를 넣어 보세요. 꾸며 낸 카드는 「일치하지 않음」이 나옵니다.
- 학생이 「처음부터 다시 하기」를 쓰면 기록 카드에 「2번째 도전」처럼 표시됩니다.

**조작 방법**
- 노트북: `WASD`/방향키 이동, `Shift` 달리기, `Space` 점프, `E` 열기, 마우스 드래그 시점, 휠 확대
- 태블릿 · 휴대폰: 왼쪽 아래 조이스틱(끝까지 밀면 달리기), 「점프」 · 「열기」 버튼, 화면 밀어서 시점, 두 손가락 확대 · 축소. 휴대폰은 **가로 화면**을 추천합니다. 느린 기기는 자동으로 가벼운 그래픽이 됩니다.

**알아 두실 점**
- 선생님 화면의 실시간 현황 · 순위표 · 동시 시작 버튼은 이 방식에는 없습니다. (필요하면 아래 3번 Firebase 실시간 모드를 쓰세요)
- 비밀 메시지는 QR 링크 안에 감춰서 들어 있습니다. 화면에는 도착하기 전까지 절대 보이지 않지만, 개발자 도구를 다룰 줄 아는 학생이 마음먹으면 미리 알아낼 가능성은 있습니다.
- QR 없이 주소(`…/저장소이름/`)로만 들어오면 기본 메시지로 하는 **연습 모드**가 됩니다.
- 아이폰은 무음(진동) 모드면 효과음이 안 들릴 수 있어요. 중국어 음성은 iPhone · iPad · 갤럭시 · Chrome · Edge 대부분에서 나옵니다.

## 2. (선택) Firebase 실시간 모드 체험하기

`firebase-config.js` 가 비어 있으면 **로컬 테스트 모드**로 실행됩니다.

1. GitHub Pages 에 올린 뒤(4~5번 참고) `…/teacher.html` 을 열고 「관리자 화면 열기」
2. **같은 브라우저의 새 탭**에서 `…/index.html` 을 열고 이름 입력 → 참가
3. 관리자 탭에서 「▶ 게임 시작」 → 학생 탭에서 3·2·1 후 출발!

> 로컬 테스트 모드는 이 컴퓨터(브라우저) 안에서만 저장됩니다. **여러 학생의 실시간 공유는 되지 않아요.** 실제 수업은 반드시 3번 Firebase 설정을 하세요. 화면에도 노란색 안내가 표시됩니다.

## 3. (선택) Firebase 설정 방법 — 실시간 현황 · 순위표가 필요할 때만

### 3-1. 프로젝트 만들기
1. https://console.firebase.google.com 접속 → Google 계정 로그인
2. **프로젝트 추가** → 이름 입력(예: `chinese-city-game`) → Google 애널리틱스는 꺼도 됩니다 → 만들기

### 3-2. 로그인 방식 켜기 (Authentication)
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. 「로그인 방법」 탭에서 **익명** → 사용 설정 → 저장 (학생용)
3. 같은 탭에서 **이메일/비밀번호** → 사용 설정 → 저장 (선생님용)
4. 「사용자」 탭 → **사용자 추가** → 선생님 이메일과 비밀번호 입력
   (이 이메일이 관리자 이메일입니다. 실제 메일 주소가 아니어도 됩니다)

### 3-3. 데이터베이스 만들기 (Realtime Database)
1. **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르(asia-southeast1)** 권장 (한국에서 가장 빠름)
3. 「잠금 모드로 시작」 선택 → 사용 설정

### 3-4. 웹 앱 등록
1. 왼쪽 위 ⚙️ → **프로젝트 설정** → 아래 「내 앱」에서 웹 아이콘 `</>` 클릭
2. 앱 닉네임 입력 → 앱 등록 (Firebase 호스팅은 체크하지 않아도 됩니다)
3. 화면에 나오는 `const firebaseConfig = { … };` 부분을 복사해 둡니다
   (나중에도 프로젝트 설정 → 내 앱 → 「구성」에서 다시 볼 수 있어요. **databaseURL** 이 들어 있어야 합니다)

### 3-5. 설정 파일과 보안 규칙 만들기 (코드 수정 없이)
1. GitHub Pages 주소의 `setup.html` 을 엽니다 (예: `https://내아이디.github.io/저장소이름/setup.html`)
2. 복사한 firebaseConfig 를 붙여 넣고, 3-2에서 만든 **선생님 이메일** 입력 → 「파일 만들기」
3. **firebase-config.js 내려받기** → 6번 방법으로 GitHub 의 `js` 폴더에 덮어쓰기
4. **규칙 복사** → Firebase 콘솔 **Realtime Database → 규칙** 탭에 전체를 붙여 넣고 **게시**

> 직접 수정하고 싶다면: `js/firebase-config.js` 에 값을 넣고, `database.rules.json` 안의 `teacher@example.com` (11곳)을 모두 선생님 이메일로 바꿔 규칙 탭에 붙여 넣으면 됩니다.

### 무료 요금제 한도 (참고)
Realtime Database 무료 요금제는 동시 접속 100명, 저장 1GB, 월 다운로드 10GB입니다. 한 반 30명 수업에는 충분합니다. (MP3 를 많이 올리면 다운로드 양이 늘어나니 파일당 100KB 안팎을 권장합니다)

## 4. GitHub 저장소에 올리는 방법

1. https://github.com 가입 · 로그인
2. 오른쪽 위 **＋ → New repository**
   - Repository name: 예) `chinese-city` (영문 권장)
   - **Public** 선택 (무료 GitHub Pages 는 공개 저장소에서 작동)
   - Create repository
3. 새 저장소 화면에서 **uploading an existing file** 링크 클릭
4. 내려받은 zip 의 압축을 풀고, **폴더 안의 내용물 전체**(index.html, teacher.html, css, js, vendor … )를 브라우저 창으로 끌어다 놓기
   - 폴더째로 끌어다 놓으면 하위 폴더 구조가 그대로 올라갑니다
   - `index.html` 이 저장소 **맨 위(루트)** 에 보여야 합니다
5. 아래 **Commit changes** 클릭

2. Source: **Deploy from a branch**
3. Branch: **main** / 폴더: **/(root)** → **Save**
4. 1~3분 후 같은 화면 위쪽에 주소가 나타납니다:

## 9. 실제 수업 운영 방법 (권장 순서)

**수업 전 (5분)**
1. 관리자 → 🔒 비밀 메시지 입력 → 저장 (예: 春 天 快 乐 …)
2. ⚙️ 게임 설정에서 제한 시간 확인 (기본 20분)
3. 🧹 「게임 결과 초기화」 → 상태가 「대기 중」인지 확인
4. 교사용 PC 에서 학생 화면을 한 번 열어 소리가 나는지 확인

**수업 중**
1. 학생 접속 주소 공유 → 학생 이름이 대시보드에 모두 뜨는지 확인 (접속 중 초록 점)
2. 「你去哪儿？」「往左拐 / 往右拐 / 一直往前走」 표현을 짧게 복습
3. **▶ 게임 시작** → 학생 화면에 3·2·1 → 开始！
4. 학생은 미션(我去○○。)을 보고, 중국어 안내를 들으며 이동 → 보물상자에서 E → 메시지를 학습지에 기록
5. 10개를 모으면 자동 「완주」 처리, 순위는 **서버 시각 기준**(학생 PC 시계를 바꿔도 영향 없음)
6. 학생이 학습지를 들고 오면 확인 후 표의 **「제출 승인」** → 학생 화면에도 ✅ 표시
   → 최종 우승은 「완주 순위 + 학습지 승인」을 함께 보고 결정

**수업 후**
- **⏹ 종료** → 다음 반 수업 전 다시 🧹 초기화

**자주 생기는 상황**
- 학생이 컴퓨터를 바꿨어요 → 학생이 「컴퓨터를 바꿨어요」 버튼을 누르면 대시보드에 요청이 뜹니다 → 「승인」하면 기록이 새 컴퓨터로 옮겨집니다
- 같은 학생이 탭을 두 개 열었어요 → 먼저 연 탭에 「다른 창에서 접속했어요」 안내가 뜨고, 진행은 하나로 유지됩니다
- 새로고침 · 브라우저를 껐다 켰어요 → 같은 컴퓨터 · 같은 브라우저면 모은 메시지와 위치가 그대로 이어집니다
- 소리가 안 나요 → 컴퓨터 볼륨, ⚙️ 설정의 「음성 테스트」, Chrome/Edge 사용. 그래도 안 되면 관리자 화면에서 MP3 를 등록하세요 (화면에는 항상 중국어 글자와 병음이 함께 표시됩니다)
- 컴퓨터가 느려요 → 학생 화면 ⚙️ → 그래픽 품질 「낮음」 (느린 PC 는 자동으로 그림자를 끕니다)

## 11. 알아 두실 점 (정직한 안내)

- **Firebase 실제 연결은 이 개발 환경에서 직접 시험할 수 없었습니다.** 로컬 테스트 모드의 전체 흐름(참가 → 시작 → 10개 수집 → 완주 → 승인 → 새로고침 유지 → 일시정지/재개/종료/차단/초기화/컴퓨터 변경)과, Firebase 코드 경로(모의 Firebase)로 로그인 · 참가 · 수집 저장까지 확인했습니다. 수업 전에 3번 설정 후 **선생님 PC + 학생 PC 2~3대로 한 번 미리 시험**해 주세요.
- **비밀 메시지 보안**: 게임 화면은 도착 전에는 절대 메시지를 보여 주지 않고, 데이터베이스도 「게임 진행 중」에 「한 장소씩」만 읽게 막아 두었습니다. 다만 무료 요금제에는 서버 프로그램(Cloud Functions)이 없어서, 개발자 도구를 다룰 줄 아는 학생이 마음먹으면 진행 중에 메시지를 미리 엿볼 가능성은 완전히 없앨 수 없습니다. 수집 기록 · 완주 시각은 서버가 검증하므로 조작할 수 없습니다.
- **중국어 음성**은 브라우저에 들어 있는 zh-CN 음성을 씁니다. Chrome/Edge 는 대부분 기본 제공하지만, 학교 PC 설정에 따라 없을 수 있습니다. 이때는 관리자 화면에서 MP3 를 등록하면 MP3 로 재생됩니다 (목적지 이름이 들어가는 문장은 음성 합성으로만 읽습니다).
- **건물 모양**은 고정이고, 이름 · 간판 글자 · 문장 · 메시지는 관리자 화면에서 모두 바꿀 수 있습니다.
- 글꼴은 Google Fonts 에서 불러오며, 학교망에서 막혀 있으면 컴퓨터에 있는 중국어 글꼴(Microsoft YaHei 등)로 자동 대체됩니다.
